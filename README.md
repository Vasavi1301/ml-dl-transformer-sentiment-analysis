# # Comparative Analysis of Machine Learning, Deep Learning, and Transformer Models for Social Media Sentiment Analysis

## 📌 About
This project performs sentiment analysis using multiple models and compares their performance.

## 🧠 Models Used
- Naive Bayes  
- SVM  
- LSTM  
- RoBERTa  

## 📊 Dataset
Sentiment140 dataset (Twitter data) from kaggle

## 📄 Research Paper
This project includes a comparative analysis paper on machine learning, deep learning, and transformer models.

## ▶️ How to Run
Open the notebook and run all cells.
